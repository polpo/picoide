# Firmware releases

Each download contains the PicoIDE firmware (`picoide.uf2`, which includes the front panel firmware)
and the `pidectl.exe` (DOS) and `pidectl32.exe` (Windows) control utilities. See [Firmware
Updates](docs/firmware-updates.md) for how to install it.
