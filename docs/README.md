# Documentation for PicoIDE

This is the source for the PicoIDE documentation, available at [https://picoide.com/docs/](https://picoide.com/docs/).

The documentation is built with [MkDocs](https://www.mkdocs.org/) and [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) and Python package management is done with [uv](https://docs.astral.sh/uv/).

## Building

To build, install uv and run:

```
$ uv run mkdocs build
```

Source files are in `src/*.md`.
